# RAG Knowledge Assistant

A simple RAG system for document search and AI-powered answers.

## Project Goal

Build a complete Retrieval-Augmented Generation (RAG) application that can:

* Upload and process documents
* Split documents into meaningful chunks
* Create embeddings
* Store and search document information
* Retrieve relevant information for user questions
* Generate answers using an LLM
* Provide sources for answers
* Support conversational questions

## Technologies

The project will progressively use:

* Python
* Git & GitHub
* PostgreSQL
* Qdrant
* Embeddings
* LLMs
* FastAPI
* Streamlit
* Docker

## Architecture

The system will follow this general flow:

Document → Chunking → Embeddings → Vector Database → Retrieval → LLM → Answer
